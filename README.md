# Tip Top — Dry Cleaning Studio

A single-page advertisement website for Tip Top Dry Cleaning Studio.

## Quick Start

Open `site/index.html` in any browser, or serve it locally:

```bash
cd site
python3 -m http.server 8080
# → http://localhost:8080
```

## Stack

- Pure HTML, CSS, JavaScript — zero dependencies
- Fonts: Outfit + DM Sans (loaded from Google Fonts)
- Images: Unsplash (replace with your own)

## Structure

```
site/
  index.html    ← the entire site
```

That's it. One file. Deploy anywhere.
